# 🦇 BatScripted - Batman's Personal Dashboard

> A comprehensive mission management and control platform for Batman to combat crime in Gotham City (Year 2089)

## 🎯 Overview

BatScripted is an advanced dashboard system designed for Batman to:
- ✅ Manage missions and tasks
- 💬 Securely communicate with allies
- 🤖 Control equipment and machinery
- 🗺️ Track crime locations on an interactive Gotham City map
- 🎵 Enjoy music while patrolling
- 🏢 Manage Wayne Enterprises operations
- 🔐 Maintain secrecy with a clever fake cover page

## 🛠️ Tech Stack

### Frontend
- React.js - Interactive UI components
- Next.js - Server-side rendering
- Tailwind CSS - Modern styling
- Socket.io - Real-time communication

### Backend
- Node.js - Runtime environment
- Express.js - Web framework
- MongoDB - Database
- JWT - Authentication

## 📋 Core Features

✅ Mission Management System
✅ Ally Communication Platform
✅ Equipment Control Center
✅ Crime Mapping System
✅ Fake Cover Page (Gotham Gazette)
✅ Music Player
✅ Wayne Enterprises Dashboard
✅ Secure Authentication

## 🚀 Quick Start

```bash
git clone https://github.com/AasthaGupta2304/BatScripted.git
cd BatScripted

# Install dependencies
cd backend && npm install
cd ../frontend && npm install

# Run locally
# Terminal 1: npm run dev (backend)
# Terminal 2: npm run dev (frontend)
```
